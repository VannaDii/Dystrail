# How It Works

This section explains the rules behind the player choices in the [Game Guide](../). It is for readers who want to inspect replay behavior, day accounting, hearing odds, and the game's source data.

- [Rules and replay](rules-and-replay.md) explains the simulation and what a run code can reproduce.
- [Game data and builds](game-data.md) identifies the configuration files and what must be rebuilt when they change.

Numbers shown by the game at the current decision are the player-facing authority for that decision. The technical pages describe the version released with this guide; they do not promise that future versions will keep the same tuning.
