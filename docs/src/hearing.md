# The D.C. hearing

Reaching D.C. takes the surviving crew to a public hearing. The game shows starting odds before you begin and warns if the crew is worn thin. Gather receipts, build credibility, find allies, and protect the crew on the way there.

![A D.C. checkpoint in the game, with the Capitol in the distance](/play/static/img/journey/beltway.png)

Questioning can run for up to three rounds. Each completed round costs sanity and changes the influence of the crew's case. The hearing may end early if there are no further questions, or if the crew cannot continue. When questioning closes, the game shows how the completed rounds changed the starting odds. A full 100% secures the motion; otherwise a final vote decides it.

The hearing sequence presents a result already determined and stored when it begins. **Fast** changes its presentation speed, and **Skip to verdict** advances the presentation; neither is a new vote. The hearing record and final scorecard explain what happened.

After the result, you can review the journey's statistics, copy share text or the run code, replay the same code, or begin a new run. A share code repeats starting conditions and choices in the same game version; use a [backup](saving.md) to keep a specific saved journey.

For the calculation behind the odds, see [Rules and replay](how-it-works/rules-and-replay.md).
