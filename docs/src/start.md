# Start a journey

Open [Dystrail](https://dystrail.com/play/) and wait for the game to finish preparing its files. The setup screen then lets you choose a trail and use the generated run code or enter another valid one.

## Choose your trail

- **Classic** has the original political survival road trip and absurd encounters.
- **The Deep End** uses the same journey structure and opts into darker themes, including attacks on trans rights, abortion restrictions, surveillance abuse, detention, and denied care. The setup screen describes those themes before you choose.

Run codes beginning `CL-` select Classic; codes beginning `DP-` select The Deep End. Save a code if you want to replay its starting conditions. The same code **and the same choices** reproduce a journey in the same version of the game; a code alone does not preserve your progress. For an exact in-progress return, use a [save or backup](saving.md).

## Choose and name your crew

Pick one of six characters: Journalist, Organizer, Whistleblower, Lobbyist, Staffer, or Satirist. Their starting resources and advantages differ; the character screen previews them. Then enter your name and crew name. You can keep the suggested names for your companions or replace them.

## Outfit the van

The starter cart is a suggestion, not free equipment. Review its total and remaining cash, then add or remove food, water, spare parts, protection, and documents. You can even leave with an empty cart. Purchases are charged when you start the journey.

Food and water add to one shared supply stock, which holds at most 20 units. A matching spare is used when you fit it during a repair. Warm coats, ponchos, and masks protect against their corresponding conditions; a press pass can help at a permit check. Read each item's description and the departure review to see what your loadout actually contains.

When ready, choose **Start the journey**. You can return to outfitting from the review screen before paying.
