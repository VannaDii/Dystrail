# Save, resume, and play offline

The game keeps a local recovery checkpoint as you play. You can also make a manual save with **Save**, then use **Load** or the **Save / Load** panel to return to that checkpoint. A run code is for replaying a journey from the start; it is not a save file.

For a copy you control, open **Save / Load** and choose **Download backup**. The same panel can restore a backup file, or copy and import backup text. This is useful for moving a run to another device. Keep a backup before clearing browser data or switching devices: the device save and recovery checkpoint live in that browser's local storage. The game may reject a save from an incompatible version.

## Offline play

The game downloads its files for offline use. Wait until the game menu says **Ready for offline play** before disconnecting. If the download is interrupted, reconnect and use **Retry download**. Browser support and available storage affect whether offline play and installation are available. The menu offers **Install Dystopian Trail** or installation guidance when supported.

Your saves are local even when the game files are cached. Clearing site data removes both the cached game and locally stored saves, so keep an exported backup if the run matters to you.

## Controls and display

Use the visible buttons on desktop or touch screens. The game menu has **High contrast**, **Help & tips**, and a language selector. Keyboard users can use the **Skip to content** link and the controls' normal focus order; some choice menus also show number key shortcuts. Use the instructions on the current screen for those shortcuts.
